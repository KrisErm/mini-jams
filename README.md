# 🎮 Mini Jams

Коллекция небольших игр, созданных на Unity в рамках мини-джемов. Каждый джем — новая тема, ограниченное время.

## 🕹️ Игры

| Игра | Тема джема |
|---|---|
| Спаси принцессу | Вот это поворот |
| Небесная канцелярия | Наоборот получилось |
| Бублик съел реальность | Вот такая фигня собачка |
| Годный год | Круглый год |
| Второй шанс | Второй шанс |
| Выбираю тебя, человек! | Сегодня тот самый день |

## 📥 Как поиграть

Готовые сборки для Windows доступны в разделе [Releases](https://github.com/KrisErm/mini-jams/releases).

1. Выберите интересующую игру.
2. Скачайте ZIP-архив из раздела **Assets**.
3. Распакуйте архив и запустите `.exe`.

## 🛠️ Исходные проекты

Исходники игр находятся в соответствующих папках репозитория.
