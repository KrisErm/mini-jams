# Проверка обновления 3 в Unity

- [ ] Нет ошибок компиляции. Обновление интерьера завершилось; вступление осталось прежним.
- [ ] В начале и при смене комнат нет обучающих остановок, списка целей или индикатора ключа.
- [ ] Ключ подбирается, решётка открывается; есть только подсказка взаимодействия рядом с предметом.
- [ ] Выкрики стражи появляются по одному, не останавливают движение.
- [ ] Высокий ящик темнеет от первого удара, разрушается от второго. Сзади стены ящик не получает урон. Обломки не блокируют проход.
- [ ] Через склад нельзя пройти до разрушения преграды; после разрушения одной колонны на каждой преграде проход свободен.
- [ ] Обходы перегородок в коридоре и приёмной проходимы, враги не застревают.
- [ ] Падение с моста/урон возвращает к ближайшей точке. Разрушенные ящики не восстанавливаются.
- [ ] Все три ряда шипов можно пройти; рычаг открывает следующую решётку.
- [ ] Приближение к принцессе само запускает разговор ровно один раз, без нажатия E.
- [ ] Финальная камера направлена на персонажей; решётка, швабра, ролик со звуком и перезапуск работают.
- [ ] Замерить время первого прохождения и скорректировать маршрут при необходимости.
- [ ] Проверить ролик и управление в Windows-сборке.
