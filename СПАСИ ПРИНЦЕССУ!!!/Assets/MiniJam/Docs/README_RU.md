# Спаси принцессу — обновление 3

## Установка поверх текущего проекта

1. Останови Play, сохрани сцену и закрой Unity.
2. Если меняла JamGame.cs, сохрани свою копию вне Assets: пакет заменит скрипты. Реплики в GameConfig.asset сохраняются.
3. Распакуй SaveThePrincess_Unity_FPS.zip. Скопируй SaveThePrincess/Assets/MiniJam в Assets своего проекта с заменой файлов. Старую MiniJam не удаляй.
4. Открой Unity, дождись компиляции.
5. Выбери Mini Jam → Обновить интерьер из моих ассетов → Обновить.
6. Откроется MJ_Castle. Нажми Play. Для запуска с заставкой открой MJ_Intro.

Команда пересоздаёт интерьер. Ручная расстановка внутри MJ_Castle заменится; перед этим генератор сохраняет Generated и GameConfig в MiniJam_Backups рядом с Assets. Внешняя MJ_Intro не пересоздаётся. Не используй для обновления общую кнопку «СОЗДАТЬ СЦЕНЫ ИГРЫ».

## Что изменено

- Семь участков: караульная → склад → извилистый коридор → мост → ловушки → приёмная → тронный зал. Длина замка по оси Z выросла с 83 до 198 единиц; перегородки заставляют обходить их с разных сторон.
- 11 стражников. При обнаружении героя они показывают короткие текстовые выкрики внизу экрана: не тревожить принцессу, ей не нужна помощь, за беспорядок придётся отвечать. Это субтитры, без записанной озвучки. Одна реплика на стражника за прохождение, с общим интервалом между выкриками.
- Новая комната склада: две преграды по три высоких ящика. Ящики разрушаются двумя ударами меча (ЛКМ), после первого темнеют. Можно пробить одну колонну в каждой преграде; уничтожать все ящики не требуется. Обычные небольшие ящики тоже разрушаются, одним ударом. Обломки без коллизий исчезают через 1,2 секунды.
- Разрушенные ящики не восстанавливаются при возврате на checkpoint; при перезапуске сцены восстанавливаются. Ключ и открытые решётки также сохраняются до перезапуска.
- Убраны обучающие диалоги и остановки на входах в комнаты. Убраны постоянные цели, индикатор ключа и нижняя строка управления. У предметов остаётся локальное приглашение нажать E.
- Разговор с принцессой начинается автоматически примерно за три метра до неё. Подсказки E у принцессы нет. Сюжет, решётка, швабра и исходный MP4 со звуком сохранены.
- Модели стражи, принцессы без оружия, стены/пол/проёмы подключаются автоматически из вложенных исходных архивов. Декоративные элементы и ящики созданы из примитивов.

Маршрут рассчитан на более долгое прохождение, но минуты не замерены: Unity Editor в среде подготовки отсутствует. Скорость прохождения зависит от обхода врагов и знания пути.

## Где менять реплики

- Финал: Assets/MiniJam/Runtime/JamGame.cs, Finale и TrapEnding.
- Две последние реплики: Assets/MiniJam/GameConfig.asset в Inspector.
- Выкрики уже созданных стражников: компонент JamGuard → Warning Line. Чтобы менять реплики при будущей генерации, редактируй массив warnings в JamSceneBuilder.cs.

## Проверить финал и собрать игру

Mini Jam → Проверить финал (в Play Mode) переносит к принцессе и запускает финал. Mini Jam → 2. Проверить сцены проверяет связи. Mini Jam → 3. Собрать Windows требует Windows Build Support.
Видео остаётся в Assets/StreamingAssets/MiniJam/twist.mp4. Его нельзя удалять перед сборкой.

Пакет предназначен для Unity 6, Built-in/URP, Windows. Это исходники с генератором, не проверенная сборка exe.
