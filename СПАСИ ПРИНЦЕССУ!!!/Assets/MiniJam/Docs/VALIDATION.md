Вне Unity: синтаксический разбор 17 C# файлов; сохранение GUID существующих скриптов; неизменность метода CreateIntro; идентичность вложенных исходных архивов и видео; целостность ZIP. Проверка проходимости новых коридоров по прямоугольным препятствиям с запасом на радиус игрока и закрытия склада ящиками — отдельная упрощённая проверка геометрии, не проверка физики Unity.

Не выполнены: компиляция Unity API, импорт и визуальная проверка ассетов, Play Mode, реальное прохождение, замер длительности, сборка exe. Для проверки в редакторе есть CHECKLIST_RU.md.
